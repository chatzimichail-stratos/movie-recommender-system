# movie-recommender-system
An end-to-end movie recommender system using ML and a web dashboard.

Πως να τρέξετε το project:
1. git clone <το_url_του_repo_σας> (Κατεβάζουν τον κώδικα)
2. cd movie-recommender-system (Μπαίνεις στον φάκελο που φτιάχτηκε)
3. python -m venv venv (Δημιουργεί ένα "καλάθι" για τις βιβλιοθήκες)
4. venv\Scripts\activate (Ενεργοποιεί το "καλάθι")
5. pip install -r requirements.txt (Γεμίζουν το "καλάθι" με τις βιβλιοθήκες που χρειάζονται)
6. python src/data/download_data.py (Φορτώνουν τα δεδομένα)
